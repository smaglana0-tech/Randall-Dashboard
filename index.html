Weekly update — about 10 minutes
  1. Run it every Friday across the 4-week window: Jun 12 · Jun 19 · Jun 26 · Jul 3.
  2. In each GHL report, set the date range to Jun 8 → that Friday. This is a cumulative snapshot, not week-by-week.
  3. Read the numbers in the order shown above.
  4. Open this dashboard and click any figure to edit — email cells plus visitors / opt-ins / calls. Rates and status recalculate instantly.
  5. Update the Reporting Period label in the bottom-left sidebar to the current date.
  6. Hit Export / Print → save as PDF. That's the dated record to send Randall. Week 4 (Jul 3) doubles as the end-of-window debrief.
Export every week regardless so there's a dated trail. For a fully automated version, the path is a hosted app on the GHL API, or GHL's own native dashboard as the always-on live view.
